# Digicore Frontend Assessment

An Angular page presenting the Digicore frontend assessment. It includes a review of a sample banking transactions component and short example snippets for a runtime-configurable multi-bank UI.

The code examples on the page illustrate the proposed approach; they are not a complete banking application or production multi-bank engine.

## Requirements

- Node.js 22.22.3 or later
- npm

## Run locally

Install dependencies and start the development server:

```bash
npm install
npm start
```

Open `http://localhost:4200/`.

## Verify

Run the unit tests:

```bash
npm test
```

Create a production build:

```bash
npm run build
```
